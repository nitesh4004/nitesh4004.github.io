Project Abstract

GeoSarovar is a cloud-native geospatial intelligence platform designed to democratize access to advanced hydrological analysis. By leveraging the computational power of Google Earth Engine (GEE) and the interactivity of Streamlit, the system provides real-time, satellite-derived insights into water resources management.

01 Rainfall & Climate Analysis

Methodology

This module processes daily precipitation data to compute long-term climatologies and anomalies. It supports two primary datasets:

  • CHIRPS Daily: Infra-red cold cloud duration (CCD) observations calibrated with TRMM (0.05° resolution). Ideal for historical trend analysis.
  • GPM (IMERG): Integrated Multi-satellitE Retrievals for GPM. Provides better temporal resolution for recent storm events.

02 Rainwater Harvesting (RWH) Potential

A Multi-Criteria Decision Analysis (MCDA) approach using Weighted Overlay methodology. The system uniquely implements a "Smart Weighting" algorithm that adjusts criteria importance based on the detected terrain type.

Input Layers
  • Slope USGS/SRTMGL1_003
  • Drainage WWF/HydroSHEDS
  • Soil Texture OpenLandMap/SOL
  • LULC ESA/WorldCover
Dynamic Weight Logic
Zone: Arid (e.g., Rajasthan) Prioritizes Rainfall (35%) & Soil Infiltration (25%). Slope is less critical.
Zone: Hilly (e.g., Himachal) Prioritizes Slope (40%) & Drainage (25%) to identify runoff retention zones.

03 Water Body Encroachment (SAR)

Uses Sentinel-1 C-band SAR (Synthetic Aperture Radar) to detect surface water changes independent of weather conditions. The system utilizes the VV polarization channel, where water surfaces typically appear dark (low backscatter) due to specular reflection.

04 Flood Extent Mapping

Implements a Change Detection algorithm using Sentinel-1 GRD imagery.

  1. Pre-processing: Temporal filtering (Pre-event vs. Post-event) and Speckle Filtering (Boxcar/Lee).
  2. Ratio Calculation: Ratio = Post_Event_VH / Pre_Event_VH. Water appearance changes drastically in SAR during floods.
  3. Thresholding: A user-defined threshold (default 1.25) separates flooded pixels from permanent water bodies.
  4. Topographic Correction: HAND (Height Above Nearest Drainage) or Slope masks (< 5%) remove false positives in hilly terrain.

05 Water Quality Monitoring

Leverages Sentinel-2 MSI (Multispectral Instrument) to derive bio-optical indicators. The system applies automated cloud masking using the COPERNICUS/S2_CLOUD_PROBABILITY dataset before computing indices.
