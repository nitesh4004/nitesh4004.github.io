System Abstract

v2.0.1 | BUILD: STABLE | ENV: STREAMLIT_CLOUD

SpecTralNi30 is a high-performance geospatial intelligence platform that bridges Classical Remote Sensing with modern Foundation Models. It features a unique hybrid architecture where lightweight models (ANNs) are trained locally via Scikit-Learn, while massive-scale processing and Random Forest classification occur server-side on Google Earth Engine.

01

Spectral Monitor

Dynamic Band Math Engine

The system implements an on-the-fly raster calculator capable of processing custom algebraic expressions across optical and thermal bands. It includes an automated Dynamic Stretch algorithm that calculates the 2nd and 98th percentiles of the ROI to optimize visual contrast.

Supported Indices
  • NDVI (Vegetation) (NIR-Red)/(NIR+Red)
  • NDWI (Water) (Green-NIR)/(Green+NIR)
  • LST (Landsat Thermal) K - 273.15
  • SAR Ratio VH / VV
Auto-Stats Logic
def calculate_dynamic_stretch(image, roi): # Compute 2nd & 98th percentiles stats = image.reduceRegion( reducer=ee.Reducer.percentile([2, 98]), geometry=roi, scale=30, bestEffort=True ) return min(stats), max(stats)

03

Geospatial Foundation Models

Leverages Google's Satellite Embeddings (V1). Unlike traditional spectral bands, embeddings capture high-level semantic features (texture, context, shape) generated by massive pre-trained models. This allows for high-accuracy classification even with limited training data.

Supported Downstream Tasks
  • Alpha Earth (Transfer Learning) Extracts labels from Dynamic World and re-trains a classifier on Embeddings to smooth out noise and improve temporal consistency.
  • Unsupervised Clustering Applies KMeans clustering directly on the embedding vectors to identify latent terrain patterns without ground truth labels.
# Loading Foundation Model Embeddings embeddings = ee.ImageCollection( 'GOOGLE/SATELLITE_EMBEDDING/V1/ANNUAL' ).filterDate(f'{target_year}-01-01', ...) # Semantic Transfer Learning training_image = embeddings.addBands(dw_label) classifier = ee.Classifier.smileRandomForest(50) classified = embeddings.classify(classifier)

Landslide Detection (SAR)

Utilizes Sentinel-1 C-band SAR (Synthetic Aperture Radar) to detect ground surface changes independent of cloud cover. The algorithm identifies landslides by analyzing backscatter intensity changes combined with topographic constraints.
