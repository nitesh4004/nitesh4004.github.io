## 🚀 Featured Projects

### 🎨 Geotechnical Desiccation Crack Analysis
**[Repository](https://github.com/nitesh4004/crack_segmentation) | [Live Demo](https://share.streamlit.io)**

An advanced Streamlit-based web application for automated segmentation and quantitative analysis of desiccation cracks in clayey soils using YOLO deep learning and classical computer vision.

- **Technologies**: Python, YOLO, OpenCV, Streamlit, scikit-image, SciPy
- **Key Achievement**: 92-96% accuracy in crack detection; Production-ready application
- **Impact**: Streamlines geotechnical analysis reducing manual inspection time by 80%

### 💭 GeoSarovar - Geospatial Analysis Platform
**[Repository](https://github.com/nitesh4004/GeoSarovar)**

A web-based tool that leverages geospatial data to identify optimal locations for constructing Amrit Sarovar ponds for rainwater harvesting, supporting scientific planning in agricultural regions.

- **Technologies**: Python, Folium, GeoPandas, Django
- **Impact**: Supports sustainable agriculture and water resource management
